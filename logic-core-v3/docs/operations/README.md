# Workflows Operativos — develOP

Esta carpeta contiene los procedimientos diarios del equipo develOP.

## Workflows disponibles

1. [Onboardear un cliente nuevo](./01-onboarding-cliente.md) — ~15 min
2. [Activar un bot](./02-activar-bot.md) — ~10 min
3. [Editar la KB de un cliente](./03-editar-kb.md) — ~20 min
4. [Responder a una alerta del sistema](./04-responder-alerta.md) — ~5-30 min
5. [Manejar cliente que dice "no anda"](./05-cliente-no-anda.md) — ~10-60 min

## Quién hace qué

- **Franco**: lead operativo, cliente-facing principal
- **[Socio]**: backup operativo, especialista técnico
- **Cualquiera**: puede ejecutar workflows con docs

## Cuándo usar cada workflow

| Situación | Workflow |
|---|---|
| Cliente nuevo cerrado, hay que onboardearlo | 01 |
| Cliente onboardeado, falta activar bot | 02 |
| Cliente dice "agregá X al chatbot" | 03 |
| Email de alerta llegó | 04 |
| Cliente reporta problema | 05 |

## Antes de empezar

- Login con tu admin: `admin@develop.com` (Franco) o `socio@develop.com` (socio)
- Verificar que `STATUS.md` está actualizado
- Revisar `/admin/alerts` (no debería haber pendientes críticas sin resolver)
