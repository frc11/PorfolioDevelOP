Sitio de prueba — Widget develOP

Este es un sitio HTML estático simulando el sitio de un cliente. Si ves un botón flotante cyan abajo a la derecha, el widget funciona.

¿Qué probar?

  • Click en la burbuja → el iframe carga el chatbot
  • Escribir un mensaje → el bot responde
  • Click en ✕ dentro del chat → el widget se cierra
  • Los botones de API window.develOP abajo
